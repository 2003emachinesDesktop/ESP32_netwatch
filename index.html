ESP32 NetWatch Web Control Panel

this is the control panel, where you can set or change variables.

most of your important variables that controls how this project will run are available to be changed here in this web panel.

Important Settings:

Wi-Fi Settings:

here you can set your SSID and password.





Domains or IPs to be checked:

here you can set, change, or remove domains or IP addresses that you would like to be polled for connectivity.



Other Settings:

Cycle Time (in minutes):

this is the length of time it takes to complete a cycle (ie check all of the domains and IPs).

default value is a function using the number of domains and IPs, is calculated at runtime.

NOTE: best to leave this alone, see docs for details.



Sleep Time (in seconds):

this controls how long it will display each domain name, status code, and message on the screen.

default value is 30 seconds

NOTE: best to leave at 30 seconds, see docs for details.



Time Sync? (on/off):

this allows the user to control the time sync function.

NOTE: time sync is not required for project operation.
